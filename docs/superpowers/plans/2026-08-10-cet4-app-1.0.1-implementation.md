# CET-4 App 1.0.1 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 交付 iPhone 13 优先的 CET-4 App 1.0.1：可靠本机英语发音、跨 Tab 即时数据同步、可重复额外十词、词书浏览，以及完整中文项目首页。

**架构：** 在既有 Riverpod `Notifier` 层增加轻量数据变更版本号 Provider；数据库成功写入后递增对应版本号，保活 Tab 监听并加载自身数据。将 `flutter_tts` 从学习页面提取为可注入的本机语音服务；词书浏览在 Drift 中使用稳定排序、关键词过滤和游标式偏移分页。页面只负责展示状态和触发 Notifier/服务操作。

**技术栈：** Flutter 3.44、Dart 3.12、Material 3、flutter_riverpod 2.x、Drift SQLite、flutter_tts 4.x、flutter_test、GitHub Actions macOS iOS 构建。

```dart
@immutable
class AppDataEventsState {
  const AppDataEventsState({
    this.settingsRevision = 0,
    this.studyRevision = 0,
    this.notebookRevision = 0,
  });

  final int settingsRevision;
  final int studyRevision;
  final int notebookRevision;

  AppDataEventsState copyWith({
    int? settingsRevision,
    int? studyRevision,
    int? notebookRevision,
  }) => AppDataEventsState(
    settingsRevision: settingsRevision ?? this.settingsRevision,
    studyRevision: studyRevision ?? this.studyRevision,
    notebookRevision: notebookRevision ?? this.notebookRevision,
  );
}

class AppDataEventsNotifier extends Notifier<AppDataEventsState> {
  @override
  AppDataEventsState build() => const AppDataEventsState();

  void settingsChanged() => state = state.copyWith(
    settingsRevision: state.settingsRevision + 1,
  );

  void studyChanged() => state = state.copyWith(
    studyRevision: state.studyRevision + 1,
  );

  void notebookChanged() => state = state.copyWith(
    notebookRevision: state.notebookRevision + 1,
  );
}
```

```dart
class TtsService {
  TtsService({FlutterTts? tts}) : _tts = tts ?? FlutterTts();

  final FlutterTts _tts;
  bool _isReady = false;

  Future<void> initialize() async {
    await _tts.awaitSpeakCompletion(true);
    await _tts.setLanguage('en-US');
    await _tts.setSpeechRate(0.45);
    await _tts.setPitch(1.0);
    final voices = await _tts.getVoices;
    final voice = selectPreferredVoice(List<Map<dynamic, dynamic>>.from(voices));
    if (voice != null) await _tts.setVoice(voice);
    _isReady = true;
  }

  Future<void> speak(String text) async {
    if (!_isReady) await initialize();
    await _tts.stop();
    final result = await _tts.speak(text);
    if (result != 1) throw TtsException('系统未能开始播放英语发音');
  }
}
```

实现中还必须：注册 `setErrorHandler` 将平台错误转为 `TtsException`；在 iOS 使用插件支持的 `setIosAudioCategory`/`setIosAudioMode` 配置 `playback`；提供 `stop()` 与 `dispose()`；语音列表中先匹配 `locale == 'en-US'`，再匹配任意 `en-*`，最后返回 `null`。

- [ ] **步骤 3：实现稳定的数据库分页查询**

在 `AppDatabase` 添加：

```dart
Future<List<Word>> getWordbookPage({
  required String book,
  String query = '',
  required int offset,
  required int limit,
}) {
  final normalized = query.trim();
  final statement = select(words)..where((word) => word.book.equals(book));
  if (normalized.isNotEmpty) {
    final pattern = '%$normalized%';
    statement.where((word) => word.word.like(pattern) | word.meaning.like(pattern));
  }
  statement
    ..orderBy([(word) => OrderingTerm.asc(word.seq), (word) => OrderingTerm.asc(word.id)])
    ..limit(limit, offset: offset);
  return statement.get();
}
```

若 Drift 的 nullable `meaning` 不支持直接 `like`，使用 `word.meaning.isNotNull() & word.meaning.like(pattern)` 保持 SQL 空值语义正确。
